0.0.6 改用独立控制器适配层，保留 MaaEnd 上游 MXU 程序代码，并完善运行环境与备份清理。

- 不再分发固定版 MXU；新增启动器和 MaaFramework C API 适配层，MaaEnd 常规更新后重新应用补丁时保留新版 MXU。更换启动入口后会刷新程序和应用签名。
- 保留官方 Go/C++ Agent、MaaFramework 和业务资源；Agent 启动时仅为 EndPlayDesktop 转换桌面控制器类型，并转交原有参数。
- 自动回收闲置 Runtime 和补丁解压缓存，保护当前安装及保留备份引用的运行环境；新增“清理闲置运行环境”按钮。
- 新增“清空备份…”按钮，确认后删除本工具保存的各安装路径备份，并回收随之闲置的 Runtime。
- 运行环境不再重复携带整套 MaaFramework 动态库，补丁应用约 47 MiB；同内容源码归档不再受文件时间戳影响。

从旧补丁迁移时，工具会寻找同版本未修改备份恢复原版 MXU。缺少备份时，请先重新安装当前官方 MaaEnd，再应用新版；任务配置无需删除。迁移后重新选择 EndPlayDesktop，填写实际 MaaTools 地址并点击连接。请通过正常的 MaaEnd.app 启动。

开发者构建命令改为 `python patch.py build --app /Applications/MaaEnd.app`，不再使用 `--mxu-source` 或 `--mxu-binary`。

游戏内插件功能未变更，已有插件可继续使用；分发包仍附带插件和完整源码。未来上游 API、动态加载方式或签名策略的不兼容变更仍可能需要更新适配层。

已通过用户测试，以及 104 项 Python 测试、10 项 CTest、真实 MaaFramework v5.14.3 和 v6.0.0-alpha.1 公共 API 的模拟设备验证、应用副本签名及完整恢复验证。分发应用采用本地 ad-hoc 签名，未进行 Apple 公证。
