0.0.7 修复 macOS 菜单栏图标和后台窗口唤回。

- 保留 MaaEnd 原版启动入口，由原程序直接加载控制器适配层，移除独立启动器的 `execv()` 跳转。
- 只在 Mach-O 头部空闲空间增加动态库依赖，保留上游程序的 section 内容、偏移和构建 UUID，并重新签名。
- 转发上游 Reopen 回调，在没有可见窗口时恢复主窗口，支持 Dock 唤回。
- 新载荷为 format 4，只包含适配层；旧 format 3 启动器载荷需要重新构建。

验证范围以完整官方 MaaEnd 首次安装补丁为准。旧补丁用户可先重新安装当前官方 MaaEnd 再应用新版，任务配置无需删除。
