# 启动与关闭游戏日志文案

本文记录 0.0.4 专用任务的日志。当前补丁已改用上游 PlayCover 启动与关闭任务；GUI 启动日志由上游 Go Agent 提供，以下启动文案仅适用于保留的 `launch-game` CLI。关闭仍使用本仓库控制器。

范围：本次补丁新增的启动、等待、关闭游戏日志及相关异常提示。原有连接、识别、任务开始/完成日志保持原样，以下列出消息正文。

日志文案与主题色显示已通过用户测试，随 0.0.4 发布。

启动预任务复用现有富文本日志渲染：普通消息跟随主题色，警告与错误使用对应的主题颜色，界面消息不再带 `INFO:` 等前缀。终端直接调用仍保留原有纯文本格式。没有增加 MXU 前端补丁。

## 运行日志

| 级别 | 触发条件 | 文案 |
| --- | --- | --- |
| INFO | 游戏打开后，等待时间大于 0 | 游戏已打开，等待 {秒数} 秒 |
| INFO | 游戏打开后，等待时间为 0 | 游戏已打开 |
| WARNING | 退出请求后游戏仍未退出，尝试后备关闭方式 | 游戏未退出，正在重试关闭 |
| ERROR | 关闭目标不是终末地 | 仅支持关闭终末地 |
| ERROR | 关闭过程中发生错误 | 关闭游戏失败：{原因} |

等待秒数按实际数值显示，例如 `10`、`12.5`；不再固定显示 `10.0`。

删除独立的“启动预任务完成；后续连接按 MXU 原有流程处理”日志。等待结束后继续使用原有的“预任务执行完成”日志，避免重复输出。

## 异常提示

以下提示可能直接成为启动错误日志，或作为“关闭游戏失败：{原因}”中的原因。系统产生的文件、网络及 JSON 解析错误仍保留实际错误详情。

| 场景 | 文案 |
| --- | --- |
| 游戏路径检查失败 | 请选择 PlayCover 安装的终末地应用 |
| 游戏进程标识缺失 | 插件未提供有效的游戏进程标识，请重新连接 |
| 连接的进程身份不符 | 插件记录的进程不是终末地，请重新连接 |
| 其他安装位置的游戏正在运行 | 另一个位置的终末地正在运行，请先退出该应用 |
| 系统打开应用超时 | 打开游戏超时 |
| 系统无法打开应用 | 无法打开游戏：{错误信息} |
| 启动超时参数不合法 | 启动超时必须大于 0 且不超过 300 秒 |
| 等待间隔超出范围 | 启动后等待时间必须在 0 到 300 秒之间 |
| 游戏进程未按时退出 | 关闭游戏超时，应用尚未退出 |
| 关闭前发现进程身份变化 | 游戏进程身份已变化，拒绝终止其他进程 |
| 启动配置类型不合法 | 启动配置格式无效 |
| 游戏路径配置类型不合法 | 游戏路径选项无效 |
| 等待配置类型不合法 | 启动等待选项无效 |
| 等待时间类型不合法 | 启动等待秒数无效 |
| 插件连接描述中的进程标识不合法 | 连接描述文件进程标识无效 |

本次未改变等待时长、连接规则、关闭策略或业务任务逻辑。
